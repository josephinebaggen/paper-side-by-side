# Paper Side by Side

Open any PDF and annotate it next to the original: sticky-note comments, highlights, handwriting-style explanations and images. Save both copies as one side-by-side PDF.

Everything runs in your browser. The PDF is never uploaded, and your notes are saved only in your own browser (open the same file again and they come back).

**Use it:** https://josephinebaggen.github.io/paper-side-by-side/
